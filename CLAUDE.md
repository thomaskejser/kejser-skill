# kejser-skill

Two skill agents edit this repo, each on a different machine: `Skills` on Thomas's Mac and `kejser-skill` on the Windows machine (see `kejser-code:skill-updates`).

- Whenever you are about to modify this repo, run `git pull --rebase` first, every time, not only at session start.
  The other agent may have pushed since your last pull.
- Bump versions on top of what you just pulled, commit, and push straight away.
